# ☠️ PhantomLinkX - Advanced Phishing Analyzer

🚀 **PhantomLinkX** is a powerful cybersecurity tool designed to detect and analyze suspicious or malicious URLs using real-time OSINT techniques, domain intelligence, and heuristic-based risk scoring.

---

## 🔍 Features

* 🔗 URL Expansion (detect hidden short links)
* 🌍 Domain & IP Intelligence
* 📡 IP Geolocation Tracking
* 🧾 WHOIS Information Analysis
* ⚠️ Suspicious Keyword Detection (login, bank, KYC, OTP, etc.)
* 🧠 Risk Scoring Engine
* 🎨 Hacker-style CLI Interface
* 🛡️ Cyber Threat Detection

---

## ⚙️ Tech Stack

* Python 🐍
* Requests
* WHOIS
* TLDExtract
* Colorama

---

## 🚀 How It Works

1. Enter a URL
2. Tool expands and analyzes the link
3. Extracts domain, IP, and WHOIS data
4. Detects suspicious patterns
5. Generates a risk score
6. Displays final threat verdict

---

Reason:
